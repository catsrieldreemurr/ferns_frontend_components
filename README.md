# Fern's Component Library 
This repository is filled with codesnippets that are meant to be copy-and-pasted into other projects, to ease development.

# Project Navigation
> Top Folder: What Category the Components fit
> Subfolder: What Subcategory the components fit 

For example, a file in the ShadCN folder, inside the "Setup" Subfolder will be related to the initial setup of the ShadCN project.
